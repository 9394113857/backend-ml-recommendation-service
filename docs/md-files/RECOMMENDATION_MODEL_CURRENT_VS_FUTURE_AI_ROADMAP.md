==================================================================
CURRENT RECOMMENDATION MODEL
==================================================================

Current Table

recommendations

Purpose

Stores Top-K product recommendations generated by
the ML Recommendation Pipeline.

Each record represents one recommended product
for one user.

Composite Primary Key

user_id

+

product_id

Meaning

One user can have many recommendations.

One product can be recommended to many users.

Duplicate recommendations are prevented.
